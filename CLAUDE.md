# Claude Code instructions

For PinakaCTF 2026 write-up preparation, follow `SKILL.md`.

There is no fixed write-up format. Do not impose headings, sections, numbered steps, bullets, tables, captions, or a standard narrative pattern. The participant's own wording and natural flow come first.

Use the solved conversation as evidence. Include only actions the participant performed or confirms. Ask one short, neutral question only when an essential action is missing. Select 3–6 genuine screenshots and place them beside the relevant wording. If requested, create a plain DOCX containing only participant-authored text, genuine screenshots, temporary screenshot reminders where needed, and the full flag at the end.

PinakaCTF requires handwritten submissions in the participant's own words. Do not produce a supposedly human-authored submission, invent content, fabricate screenshots, or optimize for AI-detection evasion.
